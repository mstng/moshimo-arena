# もしも闘技場

**https://moshimo-arena.vercel.app**

時代も分野も違う偉人を、**共通の土俵**に乗せて戦わせるWebトイ。

信長とナポレオンが天下を争ったら。呂布とニュートンが発明を競ったら。
子どもの頃に読んだ「もし○○と○○が戦ったら？」を、大人が本気で数値にしたもの。

## 何が違うのか

同種の企画は「AIに聞いて答えを出す」形が多いが、**これは実行時にAIを呼ばない**。
判定はすべてこのリポジトリのコードで完結していて、**根拠が全部画面に出る**。

ただしデータ自体はClaude Codeと一緒に作った。96個の数値にはAIの評価のクセが入っていて、
実際それが原因で初版のバランスが壊れていた（後述の「調整の記録」を参照）。

- 16人 × 6ステータス = 96個の数値、その**すべてに史実の根拠を1行添えてある**
- 土俵ごとに重みが変わるので、**同じ2人でも土俵次第で勝敗が入れ替わる**
- 乱数を使っていないので、**同じ組み合わせなら必ず同じ結果**になる（＝検証できる）

数値そのものは作者の主観である。それを隠さず、根拠を全部晒して
「読者が反論できる形」にすることを設計の目的にしている。

## 構成

| ファイル | 役割 |
|----------|------|
| `index.html` | 画面（UIのみ。判定ロジックは持たない） |
| `arena.js` | 人物データ・土俵定義・判定ロジック |
| `test/arena.test.js` | データ整合性と判定ロジックの検証 |

ビルド不要。`index.html` をブラウザで直接開けば動く。

## ステータス

| 軸 | 意味 |
|----|------|
| 武勇 | 自ら戦う力。個の強さ |
| 統率 | 軍・組織を動かし、維持する力 |
| 知略 | 策を立て、状況を読む力 |
| 政治 | 制度・人事・交渉で勝つ力 |
| 発明 | 新しい仕組みや技術を生む力 |
| カリスマ | 地位も実績もない状態で、人が付いてくる力 |

## 土俵と重み

| 土俵 | 重み |
|------|------|
| 一騎討ち | 武勇85% / 知略9% / カリスマ4% / 統率2% |
| 会戦 | 統率45% / 知略25% / カリスマ15% / 武勇15% |
| 謀略戦 | 知略40% / 政治40% / カリスマ20% |
| 発明レース | 発明60% / 知略30% / 政治10% |
| 人心掌握 | カリスマ75% / 統率15% / 知略10% |
| 天下取り | 統率25% / 政治25% / 知略20% / カリスマ20% / 武勇10% |

重みの合計は必ず 1.0（テストで保証）。したがってスコアも 0〜100 に収まる。

## 勝率の出し方

重み付き合計のスコア差を、Eloレーティングと同じロジスティック関数に通す。

```
勝率A = 1 / (1 + 10^((スコアB - スコアA) / 25))
```

分母の `25` は勝率カーブの傾き。スコア差25で勝率およそ91%になる。
小さくすると差がすぐ振り切れてしまうため、「格上でも絶対ではない」感覚を
残せる値を選んでいる。表示は 1%〜99% に丸める（0%・100%とは言い切らない）。

## テスト

```bash
npm test
```

検証していること：

- 人物ID・名前の重複がない
- 全員が6ステータスを 0〜100 の範囲で持つ
- **96個の根拠テキストがすべて埋まっている**（このアプリの価値そのもの）
- 各土俵の重み合計が 1.0
- 勝率の合計が必ず 100、左右を入れ替えても対称
- 同じ引数なら常に同じ結果（乱数を使っていないことの保証）
- 土俵を変えると勝敗が入れ替わる（呂布 vs ニュートン）
- 不正な入力で例外が飛ぶ

## 調整の記録

初版では、全16人のうち**ジャンヌ・ダルクだけが、どの土俵でも勝率50%を超えなかった**。
カリスマ98という最高値を持ちながら、それを主役にする土俵が存在しなかったためである。

原因を追ったところ、より根本的な誤りが見つかった。作者が
**「カリスマ」と「実績による威光」を混同して**いたのである。
「有名な偉人だから人望も厚いだろう」という無自覚な前提で、征服者たちに軒並み90台をつけていた。
その結果カリスマ軸は上位が団子になり（98/96/95/94/93/90）、
仮に重みを100%にしてもジャンヌの勝率は53%にしかならない状態だった。

そこで軸の定義そのものを、次の一点に絞り直した。

> その人望は、勝ったからついてきたのか。それとも、勝つ前からあったのか。

この基準で16人すべてを再評価し、根拠も書き直した。カエサル95→84、
アレクサンドロス96→86 のように、地位や戦績が土台にある人物は下がる。
一方、地位も実績もない17歳の農民が敗け続けた国王軍を動かしたジャンヌは98のまま残る。
あわせて土俵「人心掌握」を追加し、そこから政治を外した
（政治＝制度・人事・交渉で勝つ力であり、カリスマから切り離した「地位の側」そのものだから）。

**このとき、バランスを取るためにジャンヌの数値を上げるという選択はしていない。**
土俵（ルール）は作者が自由に決めてよいが、
人物（事実の解釈）をゲームの都合で動かした時点で、根拠を公開する意味がなくなるからである。
今回動かしたのは「作者の評価が間違っていた」部分だけであり、その理由もここに残してある。

結果、全16人が勝率50%を超える土俵を持つようになった。
